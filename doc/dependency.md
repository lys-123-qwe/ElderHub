## 4. 系统功能模块
| 模块 | 主要子功能 |
| ---- | ---- |
| 用户管理 | 用户基础信息维护、角色权限配置、个人中心、安全设置 |
| 床位管理 | 床位示意图、床位信息管理、床位使用日志、床位调换 |
| 客户管理 | 客户档案管理、入住登记、退住登记、健康信息录入 |
| 护理管理 | 护理项目管理、护理级别配置、客户护理设置、护理记录、服务预约 |
| 膳食管理 | 膳食项目管理、膳食标签管理、菜单模板、客户膳食分配 |
| 慢性病管理 | 慢性病基础库、慢性病-膳食标签关联、客户慢性病配置 |
| 外出申请 | 外出申请提交、外出审批、出入登记、超时预警 |
| 系统管理 | 角色权限、系统参数、操作日志 |

## 5. 运行环境说明
### 5.1 服务器端
- 操作系统：Linux CentOS 7
- 数据库：MySQL
- 部署方式：支持私有部署 / 云服务器 X64 架构

### 5.2 浏览器端
- 操作系统：Windows 10 x64
- 兼容浏览器：火狐浏览器、谷歌浏览器
- 最低配置：8 核 CPU、8G 内存、1M 以上外网带宽
